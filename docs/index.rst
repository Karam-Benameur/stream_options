StreamOptions — Documentation
=============================

Application Streamlit pour le pricing d'options européennes
(Monte Carlo, Black–Scholes et modèle binomial).

Cette documentation présente rapidement le projet, puis la référence
de l'API Python (modules ``core.pricing`` et ``core.data_io``).
